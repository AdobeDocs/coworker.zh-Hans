# [产品]中的CX Enterprise Coworker

同事是Adobe的对话式人工智能，与CX Enterprise应用程序（如[产品]）深度集成。 它接受过Adobe最佳实践的培训，能够快速而准确地完成工作，因此您不必通过多个屏幕和工具，而是以简单的语言描述您需要的内容，例如“[example prompt one]”或“[example prompt tone]”，同事将计划工作，在连接的Adobe应用程序中运行它，并向您显示结果以供审阅。

对于[产品]，这意味着在产品中花费更少的时间[在产品中执行手动工作]，而花费更多的时间用于审阅和批准同事生成的内容。 您在每个步骤都由您控制，而同事负责计划、执行和跟进。

## 同事入门

新同事吗？ 从这里开始，全面了解它如何帮助您在[Product]和其他CX Enterprise应用程序中更高效地工作。
