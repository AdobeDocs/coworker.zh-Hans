# 协同工作插件：它们是什么、如何工作以及如何安装它们

此视频介绍插件并介绍它们如何通过新功能扩展[!DNL Coworker]。 您将了解什么是插件，它包含哪些组件，插件与技能和MCP服务器有何关系，以及如何从工作区安装、使用和删除插件。

>[!VIDEO](https://video.tv.adobe.com/v/3503665/?captions=chi_hans&learn=on&enablevpops)

## 什么是插件？

插件是适用于Adobe Co-worker的一组可安装的相关功能。 将其视为针对特定业务功能或用例而设计的现成工具包。

插件可以包括：

- 执行特定任务的专业技能
- 将同事连接到外部Adobe解决方案和服务的MCP服务器
- 捆绑的功能简化了部署和管理

## 了解关键概念

此视频介绍了几个重要组件之间的关系：

| 组件 | 用途 |
|-----------|---------|
| 市场 | 发现可用插件的目录 |
| 插件 | 可安装的功能包 |
| 技能 | 执行特定任务的可重用指令 |
| MCP 服务器 | 与外部工具和服务的受控连接 |

连接的Adobe解决方案的示例包括：

- Adobe Journey Optimizer
- Real-Time CDP
- Adobe Target
- Adobe Workfront

## 治理和安全

一个关键收获是，安装插件不会绕过组织治理控制。

同事们仍然很敬重：

- 用户权限
- 访问控制
- 审批要求
- Adobe组织治理策略

安装插件不会自动授予对用户尚未获得使用权限的产品或操作的访问权限。

## 删除插件

本视频的结尾部分演示了如何在不再需要某个已安装插件时将其删除。

删除插件也会删除该包中捆绑的功能。

## 外卖钥匙

插件通过将相关技能打包并管理连接至可安装的解决方案中，使Co-worker可扩展。 市场可帮助用户发现插件、技能执行特定任务，以及MCP服务器以安全可控的方式将同事连接到Adobe Experience Cloud应用程序和服务。
