# 创建您在同事中的第一个技能

在此视频中，您将了解零售分析师如何使用同事和Customer Journey Analytics (CJA)在紧迫的截止日期内准备高管业务绩效简报。
 
分析师不会手动构建报表和解释量度，而是与同事合作，以：

- 将业务问题映射到可用的KPI
- 验证报表覆盖范围
- 找出可用量度中的差距
- 生成可用于执行的报告
- 解释结果并总结关键调查结果
- 将分析转换为可重复使用的技能

结果是一个可重复的工作流，只需一个简单的提示即可按需执行。

>[!VIDEO](https://video.tv.adobe.com/v/3502323/?learn=on&enablevpops)

## 将分析变成可重复使用的技能

分析师没有保存单个答案，而是要求Co-worker保存用于创建分析的方法。

Co-worker识别循环模式，提取工作流，并创建将来可以再次执行的可重用技能。

## 配置动态时间范围

由于绩效报告每月进行一次，因此分析师会配置使用动态日期范围的技能。 这样可让未来执行自动分析最相关的报告周期，而无需手动更新。

## 发布并优化

在查看生成的技能后，分析师会发布该技能以供将来使用。 该技能以后可以细化，以解决KPI差距或随着报告要求的变化支持其他业务问题。
