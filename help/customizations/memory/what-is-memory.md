# [!DNL Coworker]内存：个性化人工智能，以获得更高效率的工作流

[!DNL Coworker]内存通过记住对您的工作最重要的偏好、更正和工作样式，帮助创建更一致、更高效和更个性化的交互。

Memory让同事可以在不同会话间传递所选信息，而不是每次开始新对话时重复相同的说明，从而帮助提供更快、更相关的响应。

>[!VIDEO](https://video.tv.adobe.com/v/3503657/?learn=on&enablevpops)

## 了解内存

内存设计用于跨对话保留有用的信息，包括：

- 首选响应格式
- 工作样式和通信首选项
- 商业术语
- 专业上下文
- 报告默认值和分析首选项
- 时区设置

例如，如果您始终喜欢简洁的项目符号答复或针对业务对象使用特定的术语，则同事可以记住这些偏好，并在将来的对话中自动应用它们。

## 内存与对话历史记录

内存和对话历史记录有不同的用途。

### 对话历史记录

对话历史记录允许您：

- 返回以前的聊天
- 查看以前的讨论
- 引用过去的交互

### 记忆

内存允许协同工作：

- 保留所选的首选项
- 应用已保存的更正
- 个性化未来的互动
- 提高跨会话的一致性

内存是一个个性化层，而不是每次对话的记录。

## 内存与业务环境

不应将内存与业务环境混淆。

### 业务上下文

业务上下文在组织信息中考虑同事，例如：

- 公司数据
- 支持
- 治理框架
- 连接的企业系统

### 记忆

内存侧重于个人用户及其偏好。

它有助于个性化交互，但不会替换组织数据源、权限或治理控件。

## 将首选项存储在内存中

保存信息的最简单方法之一是在对话中清楚地说明它。

示例包括：

- 专业角色和职责
- 首选通信样式
- 报表首选项
- 时区信息
- 常用术语

使用短语，如“记住……” 允许同事确定应保留供将来会话使用的首选项。

## 实际示例：促销活动效果报表

此视频演示了内存如何使用Customer Journey Analytics简化报表工作流。

在示例中：

1. 用户请求营销活动效果报表。
2. Co-worker标识数据源和报告组件。
3. 用户将首选报告设置保存到内存。
4. 同事会在未来分析中自动应用这些首选项。

因此，使用用户首选的维度、量度和报告假设来传送后续报告，而不需要额外的说明。

## 管理内存

用户可以控制存储在内存中的信息。

在&#x200B;**自定义>内存**&#x200B;中，用户可能能够：

- 启用或禁用内存
- 查看存储的首选项
- 检查单个内存条目
- 编辑保存的信息
- 删除不再有用的记忆

可用控制可能因组织设置以及管理员启用的Adobe体验而异。

## 重要注意事项

内存是为个性化而设计的，而不是作为记录系统。

不要依赖内存作为下列操作的授权源：

- 客户数据
- 营销活动效果数据
- 法律要求
- 法规遵从性决策
- 安全决策

内存也不会：

- 授予对Adobe产品的访问权限
- 提供其他权限
- 覆盖治理控制
- 替换组织数据系统

始终遵循组织的治理策略和管理员指导。

## 关键要点

Adobe Co-worker Memory通过在对话中执行重要偏好和更正来帮助减少重复指令，以及创建更加个性化的AI体验。

通过记住您喜欢的工作方式，Co-worker可以随着时间的推移变得日益有用，同时仍能够在您的组织建立的治理和安全控制范围内工作。
