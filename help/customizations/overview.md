# 同事自定义概述 {#overview}

自定义功能允许您扩展和个性化同事，以适合您团队的工作方式。 使用技能标准化可重复的工作流、使用集成将同事连接到其他系统、使用插件将相关功能捆绑到一个可安装的包中，以及使用内存在对话中传递您的偏好和工作风格。
