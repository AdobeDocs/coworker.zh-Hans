# 审核同事事件 {#audit}

了解如何在Adobe CX Enterprise Coworker中审核事件。 审核为管理员提供了同事在其组织中执行的操作的记录。

>[!NOTE]
>
>您的组织必须启用才能让同事使用此功能。 审计将逐步可用，并且在启动时可能没有为所有同事组织启用。 有关详细信息，请参阅[获取有关访问权限的帮助](/help/administration/access-control.md#get-help-with-access)。
