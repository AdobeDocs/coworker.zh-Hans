# 关于同事聊天 {#overview}

同事聊天是一种用于完成客户体验工作的对话界面。 您用简单的语言描述了目标（例如，“构建春季瑜伽促销活动的受众”或“告诉我为什么这个受众上周在收缩”），Co-worker Chat规划工作，在您的Adobe和连接的系统中执行工作，验证结果，然后将完成的工作交还给您进行审批。

其价值：过去跨多个屏幕、团队和天的工作现在只需几分钟即可在一个对话中完成。 您可以委派结果，并通过审阅和批准来保持控制；同事聊天可以执行相关步骤、在此过程中从错误中恢复，并在了解您的团队的工作方式时变得更加敏锐。

若要开始使用，请参阅[开始使用同事聊天](ui-guide.md)。

>[!AVAILABILITY]
>
>同事聊天功能现已正式推出。 功能和连接的应用程序继续扩展。 检查可用的[技能](./use-cases/workflows.md)和连接器部分以了解当前支持的内容。

>[!NOTE]
>
>同事聊天是Adobe CX Enterprise Coworker的一个模块。 其他两个模块扩展了同一个基础：团队协作（从一个对话中站起来启动一个完整的营销活动）和团队协作（用于端到端、多团队工作流的始终在线工作区）。 本页介绍“同事聊天”。

## AI助理的演变

同事聊天是[AI助手](https://experienceleague.adobe.com/zh-hans/docs/cx-enterprise-ai/experience-cloud-ai/ai-assistant/ai-assistant-ui)和Adobe Experience Platform Agent Orchestrator之后的下一步。 目前，您在AI Assistant中可执行的所有操作（包括产品知识以及操作和数据洞察）均继续可用。 同事聊天使用共享的[同事构建基块](/help/home.md#building-blocks)来完成对话工作，而不仅仅是回答问题。

## 聊天体验

* **丰富的对话内结果：**&#x200B;图表、表格和交互式项目可在您工作的位置内联渲染。 您可以上传图像供Co-worker使用，并在对话中预览PDF，而无需在工具之间切换。
* **它显示其工作：**&#x200B;当同事聊天处理任务时，您可以查看其原因和进度（加载适当的技能、检查您的数据模型、运行合规性检查、查找重叠），因此您始终知道它在做什么以及为什么。
* **长而复杂的会话：**&#x200B;同事聊天支持扩展的多步骤会话，并在这些会话间保留上下文，因此您可以在一个位置从头到尾处理问题。
* **建议和后续提示：**&#x200B;同事聊天提出后续步骤，因此您不必猜测要问什么。
* **对话历史记录：**&#x200B;已保存过去的对话，以便您可以返回以前的工作，从中断的地方取回并重复使用同事聊天内容。
* **内置反馈：**&#x200B;对任意响应进行评级，只要拇指竖起或拇指低下，就可以告诉同事聊天什么有效、什么无效；您的反馈有助于随着时间的推移改善体验。
