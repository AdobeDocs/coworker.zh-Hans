# Adobe Journey Optimizer与同事 — 提出忠诚度挑战并显示见解

在本演示中，您将了解如何在同事中使用Adobe Journey Optimizer (AJO)忠诚度来简化和加快忠诚度计划管理。
 
此视频展示了忠诚度插件及其挑战管理技能，这是一项AI支持的功能，可帮助营销人员使用自然语言而不是手动配置用户界面中的每个设置来创建、编辑和管理忠诚度挑战。
