# 规划Adobe Content Analytics实施

了解CX Enterprise Coworker中的《ACA实施指南》如何创建量身定制的Adobe Content Analytics实施计划，无论您是将Content Analytics添加到现有Customer Journey Analytics (CJA)部署，还是从独立设置开始。

## 您将学习的内容

- Co-worker如何使用引导式发现过程捕获许可、渠道、SDK、行为数据、身份拼接、隐私和报告要求。
- 指南如何安排实施阶段、分配所有者、标识依赖项以及估计关键路径时间线。
- 现有CJA部署与独立Content Analytics实施之间的计划有何不同。
- 如何跟踪进度、修订假设并将实施任务导出到CSV和Jira。

>[!VIDEO](https://video.tv.adobe.com/v/3508620/?learn=on&enablevpops)

## 将Content Analytics添加到现有CJA部署

第一个演练从已通过Web和移动设备使用CJA的组织开始。 Adobe Tags和Web SDK支持该网站，Mobile SDK支持这些应用程序，并且CJA连接、数据视图和数据流已经存在。

根据回答，Co-worker制定一个计划，其中考虑成功实施所需的所有任务以及实施团队控制之外的依赖关系。

## 从独立Content Analytics开始

第二个演练从没有现有CJA部署开始。

同事会生成一个计划，其中包括与Adobe客户团队确认行为数据要求，并为Web行为数据创建架构和数据集。 引导式向导用于创建CJA连接和数据视图。

## 跟踪进度并导出计划

该视频演示了一个交互式单页跟踪器，其中的步骤可以标记为完成、重新打开或延迟。 当实施详细信息更改并重新生成其文件时，同事可以更新计划。

本指南支持其他导出格式，包括：

- **CSV：**&#x200B;包含阶段、工作量、所有者、依赖项和状态的实施步骤。
- **Jira：**&#x200B;积压就绪结构，阶段为史诗，步骤为故事，包括优先级和故事点。

## 关键外卖

Adobe Co-worker中的《ACA实施指南》可将实施要求转化为按顺序排列的可操作计划。 它通过尽早适应您的开始环境并显示安全性、隐私和配置依赖关系，可帮助团队协调和跟踪Adobe Content Analytics的推出。
