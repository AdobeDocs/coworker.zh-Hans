# 关于同事项目 {#overview}

>[!AVAILABILITY]
>
>同事项目处于有限可用状态。 请联系您的Adobe客户代表，以了解有关如何参与的更多信息。

同事项目是一种共享体验，其中从业人员使用可重用工作流完成端到端客户体验工作。 工作流将人员、代理、技能和业务上下文整合在一起，可跨Adobe CX Enterprise和第三方应用程序使用。 治理和人的决定从头到尾指导工作。

授权用户可以创建、发布和管理项目模板。 从业者使用模板启动业务计划项目、与其团队协作并在批准门槛处做出决策。

>[!NOTE]
>
>同事项目和[同事聊天](/help/chat/overview.md)是Adobe CX Enterprise Coworker的模块。 本页介绍同事项目。

## 包含的项目模板 {#project-templates}

从用于常见营销用例的包含模板开始。 每个模板都提供了一个可重复的工作流，您可以根据业务需求进行调整。 从这五个模板中进行选择，以在同事项目中启动项目。

### 统一受众和编排的历程 {#unified-audiences-orchestrated-journeys}

规划、启动和衡量客户历程中的B2C营销活动。 可使用Adobe Real-Time CDP构建和激活受众，并使用Adobe Journey Optimizer通过Launch编排营销活动。 使用Adobe Customer Journey Analytics了解性能。

遵循决策、验证、批准和衡量的可重复流程。 应用贵组织的品牌、同意、法律和治理要求。

必需的兼容应用程序：Adobe Workfront和Marketo Engage。

### 营销活动启动的企业简报 {#enterprise-brief-campaign-launch}

将B2B营销活动简报转换为准备执行的电子邮件营销活动。 在Workfront中管理规划和协作，并在[!DNL Adobe Marketo Engage]中构建和准备营销活动。

在发送之前完成质量检查和所需的批准，然后在Workfront中捕获结果。 遵循从规划到执行和衡量的可重复路径。

必需的兼容应用程序：Adobe Journey Optimizer (B2C)、Real-Time CDP和[!DNL Adobe Customer Journey Analytics]。

### 付费媒体营销活动 {#paid-media-campaign}

通过协调的工作流，规划、启动和优化付费媒体促销活动。 从Workfront中的目标、预算、时间、目标和预期结果开始。 跨Real-Time CDP、[!DNL Adobe GenStudio for Performance Marketing]和[!DNL Adobe Experience Manager Assets]协调受众、创意和定位。

发布之前完成验证并花费授权。 然后，查看优化建议并关闭活动。

必需的兼容应用程序： [!DNL Adobe GenStudio for Performance Marketing]、Real-Time CDP、[!DNL Adobe Experience Manager Assets]和Workfront。

### 营销活动和历程运行状况观察 {#campaign-journey-health-watch}

监控Journey Optimizer中营销活动和历程的运行状况。 在配置的监视窗口中查看实时历程及其关联的受众。 识别发布、停止或投放事件失败的营销活动，并查看可能的原因和建议的后续步骤。

跨审阅跟踪新发现、仍未完成或已解决的审阅结果。 无需更改Journey Optimizer即可监控问题。

必需的兼容应用程序：Journey Optimizer。

### 试验性能评审 {#experiment-performance-review}

审查试验性能并确定要采取的操作。 使用Adobe Journey Optimizer和[!DNL Adobe Customer Journey Analytics]中的试验功能以一致地评估活动试验。

在定期审查期间捕获调查结果和决策。 确定入选体验何时准备好前进或哪些体验表现缺佳时需要采取行动。

必需的兼容应用程序：Journey Optimizer和Customer Journey Analytics。

## 项目体验 {#project-experience}

使用同事项目围绕您的业务目标协调工作流：

* **目标的工作流：**&#x200B;设计和部署可协调多个代理的工作流，并具有治理和人工审批权限。
* **自适应执行：**&#x200B;通过事件、信号或计划触发工作。 同事根据您的目标评估结果，并根据结果调整或触发操作。
* **Collaboration和批准：**&#x200B;审核、批准共享项目并在其中执行操作，整个工作流中的上下文可供利益相关者使用。
