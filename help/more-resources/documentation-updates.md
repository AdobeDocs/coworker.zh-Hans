# 文档更新 {#documentation-updates}

使用本页可在CX Enterprise Coworker文档中查找新增的和显着更新的内容。 按月列出更新，最新更新排在首位。 有关团队同事的产品更改，请参阅[团队同事发行说明](../coworker-for-teams/release-notes.md)。

## 2026年11 {#nov-2026}

**2026年11月10日**

* 已更新：[开始使用同事聊天](../chat/ui-guide.md)。 可用性表现在列出了Customer Journey Analytics B2B edition、Content Analytics和Marketing Campaign Analytics。 身临其境的体验适用于这三种。 Customer Journey Analytics B2B edition和Content Analytics中提供了产品内体验，Marketing Campaign Analytics即将提供该体验。

**2026年11月4日**

* 已更新：[询问有关您内容的问题](../chat/use-cases/data-insights/ask-content-questions.md)。 具有`analyze-content`技能的内容分析现已正式推出。

**2026年11月3日**

* 新： [使用同事模拟历程](../chat/use-cases/journeys/simulate-journey-using-coworker.md)

**2026年11月2日**

* 已更新：[CX Enterprise Coworker概述](../home.md)和[同事聊天入门](../chat/ui-guide.md)。 Adobe Analytics现已作为提供同事聊天功能的应用程序列出。
* 已更新：[同事聊天工作流](../chat/use-cases/workflows.md)。 本文现在列出了检查AEM工作流和探索Dispatcher见解的技能。 它还添加了库存分发、库存运行状况、谱系和重复检测的受众技能，并指出，受众创建支持B2C和B2B受众。
